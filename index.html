Grade 10 Functions — Practice Test

Based on the Functions & Relations material in the uploaded worksheet • Sections 1.1–1.4
Suggested time: 45–60 minutes
Try the test without notes first. For written-response questions, show your reasoning on paper. The automatic score covers the multiple-choice and short numerical questions; use the answer key after you finish.

Part A — Functions and Relations

1. What makes a relation a function? 1 mark
2. Is the relation {(1, 4), (2, 5), (3, 5), (1, 7)} a function? 1 mark
3. Which equation represents a function of x? 1 mark
4. Use the vertical-line test to decide whether the graph of x² + y² = 16 represents y as a function of x. Explain briefly. 2 marks
5. For y = 3, is the relation a function? For x = 3, is the relation a function? 2 marks

Part B — Function Notation

6. Let f(x) = 2 − 3x. Find f(−4). 1 mark
7. Let f(x) = 3(x − 1)² − 4. Find f(−1). 1 mark
8. Let A(x) = 2x − 5. Find A(3x − 1). 1 mark
9. Let f(x) = 3x + 4. What value of x makes f(x) = 19? 1 mark
10. Let f(x) = 3x + 4 and g(x) = x + 1. Find x such that f(x) = g(x). 1 mark

Part C — Domain and Range

11. State the domain and range of f(x) = 4x + 1 over the real numbers. 2 marks
12. State the domain and range of f(x) = √(x − 2). 2 marks
13. State the domain and range of f(x) = 3(x + 1)² − 4. 2 marks
14. State the domain and range of f(x) = 1/x. 2 marks

Part D — Applications and Reasoning

15. A freight company charges $4/kg for an order under 100 kg and $3.50/kg for an order of at least 100 kg. Let x be the order mass in kg and C(x) the cost. Write C(x) as a piecewise function. 2 marks
16. For the freight function above, calculate the cost of a 99 kg order and a 100 kg order. 2 marks
17. A ball is thrown from the roof of a 25 m building. Its height is modelled by h(t) = −5t² + 20t + 25, where t is time in seconds. What is the initial height? 1 mark
18. Using the same model, find the height after 2 seconds. 1 mark
19. For the ball model, state a realistic domain if the ball hits the ground after 5 seconds, and state the range. 2 marks
20. A square of side length 10 is drawn around an inscribed square. If x is the horizontal distance shown in the original problem, the area model is A(x) = 2x² − 20x + 100. State the domain of x and the range of A(x) for the geometric situation. 2 marks
